# Hurricanes & Resilient Fisheries

Code and data for **"Competitiveness in American Seafood Means Storm-Resilient Fisheries"**.

This repository produces two figures that characterize hurricane exposure in the Gulf of Mexico and its relationship with U.S. commercial fishing activity.

---

## Figures

### 1. Gulf Coast Hurricane Exposure Map (`results/img/map.png`)

A choropleth map of the five Gulf Coast states (Texas, Louisiana, Mississippi, Alabama, Florida) shaded by the number of named hurricanes that made landfall or passed through each state since 2000. Each state label includes key fisheries statistics:

- Jobs (employment)
- Revenue (income, $K)
- Value added ($K)
- Seafood production ($K)

**Data sources:**
- Hurricane tracks: [NOAA IBTrACS v04r01](https://www.ncei.noaa.gov/products/international-best-track-archive) (North Atlantic basin)
- Fisheries statistics: State-level estimates compiled from NOAA sources

---

### 2. Fishing Effort Time Series (`results/img/ts_effort.png`)

A before–during–after time series of U.S. commercial fishing vessel activity in the Gulf of Mexico centered on hurricane exposure events (2015–2025). Vessel activity (vessels km⁻²) is plotted for a ±45-day window around the first/last day with storm-force winds (≥ 18 m/s), highlighting three behavioral periods:

- **Preemptive** – effort drops before storm arrival
- **Shock** – suppressed activity during the storm
- **Compensatory** – rebound in the post-storm period

**Data sources:**
- Fishing effort: [Global Fishing Watch](https://globalfishingwatch.org/) daily raster tiles (U.S.-flagged vessels, `gfwr`)
- Hurricane wind exposure: NOAA IBTrACS + `stormwindmodel` R package
- Event-horizon panel: `EventHorizon` R package

```
    └── img/               # Output figures (generated by Makefile)
        ├── map.png
        └── ts_effort.png
```

---

## Usage

Run all figures:

```bash
make
```

Clean outputs:

```bash
make clean
```

Individual scripts can also be run directly with `Rscript`:

```bash
Rscript scripts/01_map.R
Rscript scripts/02_ts_effort.R
```
